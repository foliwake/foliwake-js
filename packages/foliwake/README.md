# foliwake

The `foliwake` command, under its short name: `npx foliwake login https://foliwake.example`. This package has no
code of its own; it runs [`@foliwake/cli`](https://www.npmjs.com/package/@foliwake/cli) of the same version,
which documents the commands (also at [sdk.foliwake.dev](https://sdk.foliwake.dev/reference/packages/cli)).
Install one of the two, not both: each puts a `foliwake` command on your path.
