# Security

Please report a vulnerability in these packages privately, by email to **djioev@gmail.com**, not in a public
issue or pull request. Include the package and version, what an attacker can do, and how to reproduce it.

You get an answer within a few days. A fix is released as a new version of the packages, with a note in their
`CHANGELOG.md` once users can update. All eight packages share one version: `@foliwake/blocks-contract`,
`@foliwake/block-kit`, `@foliwake/site-check`, `@foliwake/server`, `@foliwake/client`, `@foliwake/react`,
`@foliwake/next` and `create-foliwake`.

Supported versions: the latest published 0.x minor.
